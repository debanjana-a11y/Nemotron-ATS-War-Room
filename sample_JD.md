Job Title: Senior Distributed Systems Engineer
Company: CloudScale Networks
Location: Remote / Hybrid

About the Role:
We are looking for a Senior Distributed Systems Engineer to design, scale, and maintain our high-throughput global messaging and event streaming infrastructure. You will work on low-latency microservices, fault-tolerant replication protocols, and container orchestration layers supporting millions of concurrent users.

Key Responsibilities:
- Design, build, and optimize low-latency, fault-tolerant distributed backends in Go and C++.
- Implement and maintain consensus algorithms and distributed state machines (Raft, Paxos, or etcd).
- Architect high-throughput gRPC streaming interfaces and event-driven pipelines using Apache Kafka.
- Deploy, monitor, and scale containerized services across Kubernetes clusters using Prometheus, Grafana, and OpenTelemetry.
- Enforce strict SLA latency guarantees (p99 < 15ms) and maintain zero-trust security postures using HashiCorp Vault.

Requirements:
- 5+ years of production experience architecting distributed backends in Go, C++, or Rust.
- Deep hands-on experience with consensus protocols (Raft, etcd), service meshes, and distributed replication layers.
- Production proficiency with Kubernetes container orchestration, CI/CD automation, and Linux kernel networking.
- Strong background in high-volume event streaming (Kafka/RabbitMQ) and gRPC/Protobuf communication.
- Demonstrated success adhering to 99.99% system availability and p99 SLA latency targets.
